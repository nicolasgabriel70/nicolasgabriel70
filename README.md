## Projetos

### Identificador de Cobranças — Java

Aplicação desenvolvida em Java para identificar possíveis cobranças duplicadas em extratos financeiros.

O sistema realiza a leitura de um arquivo CSV contendo transações, transforma os dados em objetos Java e compara informações como estabelecimento, data e valor.

Quando encontra transações com essas informações iguais, o programa sinaliza possíveis duplicidades para conferência.

**Funcionalidades:**

- Leitura e processamento de arquivos CSV
- Armazenamento de transações utilizando ArrayList
- Comparação de datas, valores e estabelecimentos
- Identificação de possíveis cobranças duplicadas
- Geração de relatório no terminal
- Testes com diferentes cenários

**Tecnologias utilizadas:** Java, POO, ArrayList, BigDecimal e LocalDate.

> Projeto educacional desenvolvido com dados fictícios. Transações iguais não representam necessariamente cobranças indevidas.

🔗 [Ver repositório](https://github.com/nicolasgabriel70/Identificador-de-cobrancas-java)
