### ☕ Amazon Junior Software Developer Professional Certificate

**Instituição:** Amazon | Coursera

**Status:** 🔵 Em andamento

Atualmente estou realizando o programa **Amazon Junior Software Developer Professional Certificate**, oferecido pela Amazon através da Coursera.

O programa é composto por 7 cursos e aborda fundamentos de desenvolvimento de software, programação Java, orientação a objetos e outras práticas de desenvolvimento.

**Curso atual: Introdução ao Desenvolvimento de Software (1 de 7)**

Conteúdos abordados no curso:

- Fundamentos de programação com Java
- Sintaxe, variáveis e tipos de dados
- Estruturas de controle e lógica de programação
- Introdução à Programação Orientada a Objetos (POO)
- Ciclo de vida do desenvolvimento de software (SDLC)
- Ambiente de desenvolvimento e utilização de IDEs

🔗 [Ver curso na Coursera](https://www.coursera.org/learn/introduction-to-software-development)

🔗 [Ver programa completo da Amazon](https://www.coursera.org/professional-certificates/amazon-junior-software-developer)
